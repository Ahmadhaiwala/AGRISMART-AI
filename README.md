## 🚀 What is AgriSmart AI?

AgriSmart AI is a full-stack intelligent agriculture platform that combines computer vision, machine learning, and real-time weather data to help farmers make smarter decisions.

---

## 🧠 AI Modules

| Module | Description |
|---|---|
| 🦠 **Disease Detection** | Upload a leaf image → AI detects disease with confidence score |
| 🌾 **Crop Recommendation** | Get best-fit crops based on soil, NPK, season, and climate |
| 💧 **Smart Irrigation** | AI-driven irrigation decisions based on soil moisture & weather |
| 🌦️ **Weather Intelligence** | Live weather + farming action recommendations |
| ♻️ **Sustainability Score** | Measure water, resource and crop health impact |
| 🤖 **AI Farmer Assistant** | Multilingual chatbot — English, Hindi, Gujarati |

---

## 🛠️ Tech Stack

**Backend** — FastAPI · Python · PyTorch · CatBoost · RandomForest · Open-Meteo API · OpenRouter LLM

**Frontend** — React · Vite · Axios · Lucide React · React Router

---

## ⚡ Quick Start

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Open **http://localhost:5173**
